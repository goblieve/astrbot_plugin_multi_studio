# 喵蛋的多模态工作台 (`astrbot_plugin_multi_studio`)

在 QQ 或 Synology Chat 中调用 ComfyUI 生成、编辑图片和制作视频的多模态创作工作台。

- 当前插件版本：`v1.5.0`
- 插件标识：`astrbot_plugin_multi_studio`
- 作者：`Nyapoi`
- AstrBot 版本要求：`4.25.1` 或更高
- WebUI 管理页：插件页面中的「图片编辑指令」
- 项目仓库：[goblieve/astrbot_plugin_multi_studio](https://github.com/goblieve/astrbot_plugin_multi_studio)

## 功能概览

| 功能 | 当前实现 |
| --- | --- |
| Qwen 图片生成与编辑 | 自然语言工具和 /draw 使用 Qwen Image 工作流；支持文生图、多图参考编辑、画幅比例、提示词预设和 LoRA。 |
| SD 动漫生成 | 由明确的 /draw_sd 指令触发，使用独立 SD 工作流。自然语言生图不会自行切换到 SD。 |
| 菜单式改图 | 可配置多个指令组、选项、占位符和 LoRA；支持多选、排序、跨组移动以及按组绑定改图工作流。 |
| 网页局部重绘 | 浏览器手绘或自动生成遮罩；支持局部移除、遮罩内重绘、无遮罩整图重绘和可选参考图。 |
| 独立高清放大 | /放大 使用 Qwen Image 2.1 分块放大流程，不依赖普通 /draw 的工作流放大节点。 |
| 独立抠图 | /抠图 使用 BiRefNet 流程，输出透明背景 PNG。 |
| 多视图生成 | /生成多视图 提供六种生成模式；各模式提示词可在管理页配置或恢复默认。 |
| 图生视频与识图 | /img2video 调用视频工作流；/tagger 调用图像标签工作流。 |
| 任务与回传 | 图片请求进入插件本地队列；可查状态、取消任务，并在回传未确认时重发或从 ComfyUI 历史取回。 |
| 安全控制 | 可配置群/用户白名单、提示词和图片审查、管理员绕过及审查服务故障策略。 |

## 指令速查

带图片的指令可以把图片与指令放在同一条消息中，也可以引用图片后发送指令。未引用图片时，部分功能可使用当前会话最近发送的图片或最近生成的图片。

| 指令 | 用途与示例 |
| --- | --- |
| /draw 提示词 | Qwen 文生图。例：**/draw 一只在窗边晒太阳的橘猫** |
| /draw 比例=16:9 提示词 | 指定画布比例。也支持「宽高比」「长宽比」等写法；比例范围为 1:4 至 4:1。 |
| /draw 预设=名称 提示词 | 使用插件配置中的提示词预设。/提示词预设 只列出预设名称。 |
| /draw --lora 别名=0.8 提示词 | 通过别名启用 LoRA；数值同时设置模型与 CLIP 强度。/draw --lora off 提示词 可关闭 LoRA。命令 LoRA 设置优先于预设中的 LoRA。 |
| /draw_sd 提示词 | 明确调用 SD 动漫工作流。 |
| /继续改 修改要求 | 继续编辑当前会话中本人最近生成的图片；也可以附图或引用图片。别名：/继续编辑、/接着改。 |
| 配置的改图指令 | 引用原图并发送该指令，或同一条消息发送图片与指令；随后选择一个或多个菜单选项。指令名称和选项在管理页自定义。 |
| /抠图 | 对附图、引用图或最近图片去背景，输出透明 PNG。别名：/去背景、/抠背景、/rmbg。 |
| /放大 [倍数或 MP] | 独立分块放大。例：**/放大 2x**、**/放大 1.5倍**、**/放大 8MP**；不写参数时由流程按原图大小选择目标。别名：/高清修复、/超分、/upscale。 |
| /生成多视图 | 显示六种模式，也可直接发送 `/生成多视图 1` 至 `/生成多视图 6`。例：`/生成多视图 5 从左侧看人物`。别名：/多视图、/三视图、/multiview。 |
| /img2video 提示词 fps=12 时长=5 | 根据附图生成视频；参数也可写帧率、长度或秒。别名：/图生视频、/生视频、/i2v。 |
| /tagger | 识别附图标签。别名：/tag、/标签。 |
| /lora清单 | 返回当前工作流可用的 LoRA 别名和使用方式，不显示模型文件名。别名：/可用lora。 |
| /提示词预设 | 列出 /draw 提示词预设名称，不显示预设内容。 |
| `/测试绘图` | 从 AstrBot 请求已配置的 ComfyUI `/system_stats`，检查接口能否返回 HTTP 200。无需附图，也不消耗采样任务。 |
| `/重画` | 用当前会话本人最近一次可复用的参数重新生成。别名：`/再来一张`、`/重roll`、`/reroll`。 |
| `/绘图状态 [任务编号]` | 默认显示本人在当前会话最近 5 条任务。运行中可查看阶段、采样步数和预计剩余时间，后端提供数据时附显存用量。 |
| /取消绘图 [任务编号] | 取消本人仍在排队或 ComfyUI 正在执行的图片任务。 |
| /重发图片 [任务编号] | 重发指定的失败回传任务；不带编号时尝试重发当前会话最近的可恢复任务。 |
| /释放显存 | 仅管理员可用；请求 ComfyUI 卸载模型并释放显存/缓存。别名：/清理显存、/comfy_free。 |
| /撤回 | 引用要撤回的消息后使用；仅支持 aiocqhttp。别名：/delete、/recall。 |

AstrBot 的自然语言图片工具会把普通文生图交给 Qwen 工作流；用户明确输入 /draw_sd 才会调用 SD。命中的绘图指令会结束该次普通对话分发。管理员可在 `/draw` 或 `/draw_sd` 后使用 `$enable_censorship`、`$disable_censorship` 切换当前群的审查设置，也可使用 `$add_block_tag`、`$remove_block_tag`、`$add_output_block_tag`、`$remove_output_block_tag` 管理输入与输出词表。

## 菜单式改图

在 AstrBot 插件管理页打开「图片编辑指令」，可配置多组触发指令。每组可包含多个选项，并可设置选项名称、图片编辑提示词、一个或多个 LoRA 及强度、提示词占位符、选项顺序和跨指令组移动。指令组可绑定默认 Qwen 改图工作流、遮罩工作流，或设置为网页局部重绘入口。

1. 引用原图发送已配置的指令，或同一条消息附图并发送指令。
2. QQ 中引用机器人发出的菜单，回复选项名或序号，例如 `1,3`。Synology Chat 中在原会话直接回复。
3. 可用 **2=值1/值2** 按占位符在提示词中的首次出现顺序一次填写多个值；没有填完时，机器人会一次询问所有缺项。
4. 追问后可以一次回复补齐；回复「跳过」会移除未填写占位符并继续生成，回复「取消」会取消本次改图。
5. 可用 **2+补充要求** 在该选项提示词末尾追加要求。

同一张菜单可重复选择，成功选中时刷新 10 分钟有效期。回复「取消」可关闭菜单。一个 LoRA 被多个已选选项重复指定时，使用菜单顺序靠前选项的强度。选项中的「放大」是后处理控制，不会并入编辑提示词；单独选择放大时只处理原图。ComfyUI 不可达并回退到 GPT Image 时，LoRA 和放大会被忽略，其他编辑要求仍可提交。

管理页还提供工作流库、多视图提示词管理、诊断信息和恢复上一版菜单配置。

## 网页局部重绘

将指令组设为网页局部重绘入口。QQ 中引用图片发送该指令，机器人私聊编辑链接，生成结果回到发起指令的会话。取不到原图时也可在网页上传。Synology Chat 的编辑链接仅在与机器人的私聊中发放。编辑链接默认 15 分钟过期。需要配置 mask_editor_public_url，并让 HTTPS 入口通过反向代理或 Cloudflare Tunnel 到 AstrBot 容器的 6192 端口；该项留空时网页编辑入口不可用。

页面提供原图上传/更换、拖拽上传、画笔和橡皮、笔刷预览、画布缩放与移动、遮罩扩张/收缩和羽化、填补闭合遮罩漏洞，以及参考图 2 上传。原图分块上传时每块 1 MiB，最多两块并发。网页在预览图上绘制遮罩，带遮罩提交时映射回原图尺寸。无遮罩整图编辑会先按 1200 万像素、长边 8192 像素和转换后 20 MiB 的限制准备输入，必要时等比缩小。

### 自动遮罩

自动遮罩可以用中文或英文描述目标。中文目标先尝试翻译为英文，再交给 SAM3；流程会组合匹配到的多个实例，并对自动选区稍作扩张和细小裂缝填补。识别在后台运行，页面可查询结果；识别失败时仍可手工修正或绘制遮罩。自动识别依赖 ComfyUI 中的 SAM3 节点和模型。

### 局部重绘的分支

遮罩工作流配置了可选分支时，行为如下：

| 输入 | 流程 |
| --- | --- |
| 有遮罩、无提示词 | 走选区移除分支。 |
| 有遮罩、有提示词 | 只重绘遮罩选区。 |
| 无遮罩、有提示词 | 走整图重绘分支。 |

如果工作流未绑定这组三个可选分支，则需同时提供遮罩和提示词。参考图 2 只在所绑定的遮罩工作流支持第二张图片输入时可用。

### 图片限制

- 普通改图菜单原图上限为 20 MiB。多视图菜单及直接指定模式的原图上限均为 48 MiB。
- 原图支持静态 JPG、PNG、WebP、BMP、TIFF，最大 48 MiB、6400 万像素。
- 网页预览最多约 300 万像素且长边不超过 2048 像素；提交时遮罩映射回原图尺寸。
- 遮罩最多 8 MiB；参考图 2 支持静态 JPG、PNG、WebP，最多 8 MiB、1200 万像素。
- 局部重绘还受显存、ComfyUI 工作流节点及模型本身限制；过大图像可能运行较慢或需要降低尺寸。

上传原图会计算 SHA-256。同一用户在缓存有效期 24 小时内再次上传字节完全相同的原图时，可复用已有预览。原图与预览共享 512 MiB 磁盘缓存预算，较旧条目可能提前淘汰。插件向 ComfyUI 上传输入图时另有按内容哈希复用文件名的进程内缓存。

## 独立放大、抠图和多视图

### 独立放大

/放大 使用插件内的 Qwen Image 2.1 分块高清放大流程，基于单张输入图生成，不调用普通 /draw 工作流的放大节点。可在当前消息附图、引用图片或使用最近图片。不同源图大小会选择不同的目标分辨率和处理步数；超大图按要求提供倍数。

放大流程依赖插件随附的放大 API 工作流及 ComfyUI 所需的分块放大、自定义节点。ComfyUI 不可达时不会回退到 GPT Image 放大。

### 独立抠图

/抠图 通过 BiRefNet 背景移除节点生成透明通道 PNG，不需要提示词菜单。需要在 ComfyUI 安装并加载 LoadRembgByBiRefNetModel、RembgByBiRefNet 对应节点及模型。ComfyUI 不可达时不提供抠图回退。

### 多视图

`/生成多视图` 可在菜单中单选，也可附图直接发送模式编号。在「图片编辑指令 → 多视图提示词」可编辑模板或恢复默认值。

| 编号 | 用途 |
| --- | --- |
| 1 | 偏动漫、表情较夸张的人物表情图 |
| 2 | 偏写实的人物表情图 |
| 3 | 动作差分，12 张分图、24 个姿势 |
| 4 | 多角度，12 个机位 |
| 5 | 自定义动作或角度，生成单图。在菜单中可回复 `5=人物侧身回头` |
| 6 | 多角度里图，12 个机位 |

模式 3、4、6 会分别回传基准三视图和 12 格拼图。基础等待时间取全局超时与 900 秒中的较大值，再加 ComfyUI 队列等待补偿。在菜单中回复 `1,放大` 可追加分块放大。双图模式只放大基准三视图。

这些流程与普通 /draw 提示词预设分开管理；修改多视图模板不会改动 /draw 预设。

## 工作流库与节点绑定

管理页的「工作流库」接受 ComfyUI 的 API 格式 JSON，并允许将工作流绑定到指令组。当前工作流库支持两类工作流：

- **Qwen 普通改图**：需绑定正向提示词、负向提示词、宽度、高度、潜空间和输出图片节点。
- **带遮罩局部重绘**：需绑定原图、遮罩、提示词和输出节点。还可选配整组三个分支绑定，以支持「仅移除」「遮罩内重绘」「整图重绘」三种模式。

页面会校验节点和输入字段并写入所需的 _meta.hub 绑定。工作流库最多 24 项，每个 API 图最大 1 MiB。不要把 ComfyUI 的前端工作流 JSON 当作 API 格式上传；应从 ComfyUI 导出 API 格式。

工作流库绑定仅影响配置的改图指令组。/draw、/draw_sd、/img2video 和 /tagger 仍使用各自的插件工作流配置；独立的 /放大、/抠图、多视图流程也不会被工作流库替换。

## ComfyUI 与 GPT Image 回退

- ComfyUI 在线时，图片任务由本地工作流执行。插件通过 ComfyUI API 提交任务，用 WebSocket 获取进度/完成事件；连接中断时会轮询历史结果。
- 启用 Codex OAuth 回退并配置支持图片生成的 OAuth 提供商后，普通 Qwen 文生图和图生图在 ComfyUI 不可达时可回退 GPT Image。当前 `/draw_sd` 也经过同一个全局回退分支，联网失败时可能向 GPT Image 提交提示词。
- 普通改图菜单的每个指令组可单独勾选「ComfyUI 无法连通时，回退 GPT Image」，默认关闭。开启后还需启用插件的 GPT Image 回退。回退时会发送提示词和参考图。
- GPT Image 回退不支持 ComfyUI 的 LoRA、局部放大和自定义节点。组合编辑中会忽略 LoRA/放大并提示；独立放大、局部重绘、抠图、多视图、图生视频和标签识别需要本地 ComfyUI。
- 回退依赖提供商已注册、OAuth 授权有效且具备图片生成能力；连接成功不代表每次请求都必然成功。

## 任务排队、图片回传和临时文件

图片任务进入本地队列时报告前方任务数。释放执行位置时，插件可优先安排相同模型组，减少切换，因此入队位置是当时的快照。队首已等待 180 秒或已被跳过两次时会优先执行。普通绘图、视频、抠图、放大和多视图入口对同一会话同一用户限制为两个排队或执行中的任务，管理员豁免。

`/绘图状态` 的预计剩余时间取自采样进度或近期同类任务耗时。运行中的长任务可在采样里程碑发送进度提示。排队时可用 `/取消绘图` 取消，ComfyUI 执行中会尝试按任务编号中断。

**重画与重发**用途不同。`/重画` 会新建生成任务，支持普通绘图、独立放大、多视图和视频。插件在内存中按会话和用户保存最近参数，有效期 30 分钟，全插件最多 32 条，重载后清空。`/重发图片` 用于取回已经生成的成品。

任务超时或 QQ 未确认图片回传时，插件保留可恢复记录，可使用 /重发图片 任务编号 重试发送，或尝试从 ComfyUI 历史取回已完成结果。QQ 图片达到 20 MiB 时，插件改用 QQ 文件附件发送；较小的图按平台限制处理，必要时会压缩。Synology Chat 私聊的图片或视频超过适配器附件上限时，如已配置可用的 HTTPS 编辑入口，可改发 15 分钟有效的下载链接。

生成文件和重发索引按插件的 7 天清理周期保留。编辑菜单回复等待 10 分钟，网页局部重绘链接等待 15 分钟；过期后重新发起即可。

## 配置说明

在 AstrBot 插件配置页设置以下类别：

| 配置类别 | 主要用途 |
| --- | --- |
| ComfyUI 连接 | API 地址、任务超时、默认消息发送方式。 |
| 工作流开关 | Qwen、SD、图生视频、Tagger 工作流文件及启用状态。 |
| Qwen 绘图 | LoRA 别名映射和提示词预设。 |
| 改图管理 | 多指令组、选项模板、占位符、选项 LoRA、工作流绑定。 |
| 局部重绘网页 | HTTPS 公网根地址 mask_editor_public_url；外部入口应转发到容器 6192 端口。 |
| GPT Image 回退 | 启用开关、Codex OAuth 图片提供商标识和健康检查超时。 |
| 访问与审查 | 群/用户白名单、输入/输出审查、模型选择及失败时放行或拦截策略。 |

变更主配置后按 AstrBot 页面提示重载插件或重启服务。只修改管理页中的改图选项或多视图模板时，页面会保存并应用配置，无需手工编辑插件数据文件。

## 常见排查

- **判断是连接问题还是工作流问题**：先发 `/测试绘图`。若显示在线但具体工作流仍报错，在管理页打开「运行诊断」查看 Qwen、SD、视频、Tagger 的加载状态和节点检查结果，再按任务编号对照 ComfyUI 执行日志。

- **自然语言生图进入了 SD**：检查是否发送了 /draw_sd；自然语言工具生图按当前实现走 Qwen。
- **没有 GPT Image 回退**：检查回退开关、OAuth 提供商注册状态、图片生成能力与授权。
- **局部重绘链接不可用**：检查 HTTPS 域名、mask_editor_public_url、Tunnel/反向代理目标和容器 6192 端口。
- **工作流导入或绑定失败**：确认上传的是 API 格式 JSON、工作流类型正确，必需节点绑定完整且输出节点有效。
- **抠图失败**：确认 ComfyUI 在线，BiRefNet 自定义节点和模型可用。
- **放大失败或内存占用高**：分块放大比普通生成更重，检查相应节点、显存和原图大小。
- **图片已生成但没收到**：用 /绘图状态 查看任务，再尝试 /重发图片 任务编号；大图可能以 QQ 文件形式发送。
